# Practical 10: Login, Logout and Sessions

CSV-backed demo authentication with password hashing, session regeneration, role checks and logout.

## Files
- `users.csv`
- `register.php`
- `login.php`
- `dashboard.php`
- `logout.php`

Open HTML files in a browser. For PHP/MySQL practicals, configure the database credentials in `config.php` and run through a PHP server (for example XAMPP). See the root README for setup notes.
