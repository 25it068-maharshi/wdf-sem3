# Practical 2: Static HTML5 StudentHub Pages

Semantic HTML page skeletons for the portal. Shared navigation is kept consistent.

## Files
- `index.html`
- `login.html`
- `register.html`
- `dashboard.html`
- `attendance.html`
- `assignments.html`
- `study-material.html`
- `timetable.html`
- `notices.html`
- `profile.html`
- `style.css`

Open HTML files in a browser. For PHP/MySQL practicals, configure the database credentials in `config.php` and run through a PHP server (for example XAMPP). See the root README for setup notes.
