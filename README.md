# WDF Semester 3 Practicals — 25IT068

Source files are grouped by practical number. Practical 1 is planning/documentation; Practical 2–14 contain example implementations aligned with the problem definitions in the supplied practical record.

## Run locally
- HTML/CSS/JS: open the relevant `index.html` in a browser. Practical 6 uses `fetch()`; run it through a local server rather than opening via `file://`.
- PHP: install PHP (or XAMPP), start Apache and MySQL where required, import each practical's `schema.sql`, update `config.php`, then open the folder through `http://localhost/...`.
- CSV practicals write data into their local folder. Do not deploy these demo credentials or CSV files to production.

## Important
These files are clean, runnable reference implementations reconstructed from the practical problem statements and visible code screenshots in the supplied PDF. They are not guaranteed to be character-for-character copies of the screenshots. Check database names/credentials and test each practical before submission.
