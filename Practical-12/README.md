# Practical 12: Event Management and Poster Upload

Admin event CRUD with image extension, MIME type and file-size validation.

## Files
- `schema.sql`
- `config.php`
- `index.php`
- `save.php`
- `uploads/.gitkeep`

Open HTML files in a browser. For PHP/MySQL practicals, configure the database credentials in `config.php` and run through a PHP server (for example XAMPP). See the root README for setup notes.
